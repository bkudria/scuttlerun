# Haiku Writer

Write haiku poems following the traditional 5-7-5 syllable pattern.

## Rules

- Line 1: exactly 5 syllables
- Line 2: exactly 7 syllables
- Line 3: exactly 5 syllables

Always format haikus with blank lines in-between poem lines:

    First line of the poem

    Separated, let it breathe

    Now we are finished
